# Typing

> [https://typing.yasinchan.com](https://typing.yasinchan.com)

> 技术分享 [https://yasinchan.com/tags/typing/](https://yasinchan.com/tags/typing/)

> 这是一个简约风格、可自定义主题和字体的在线中英文打字练习与键盘测试网站：支持限时、计时、英文、键盘测试与多人「比一比」，限时 / 计时可导入本机文稿，提供速度 / 准确率统计、结算曲线、输入回放、排行榜、登录记录和反馈系统。后续也会继续迭代更多有趣的功能，欢迎体验，也欢迎贡献你的想法或者代码~

## 主要功能

- 四种打字 / 测试模式：限时、计时、英文、键盘测试
- 多人「比一比」：创建 / 加入房间、倒计时 PK、实时进度
- 速度、准确率、结算曲线，以及与上次成绩的对比
- 限时 / 计时支持「选择文稿」：限时仅长文预设，计时为中 / 长句预设；本机文稿单篇最多 888 字，支持多篇上传、编辑、拖拽排序、删除、批量导出 zip，不计入排行榜
- 输入回放、排行榜、个人打字记录
- 深色 / 浅色主题、自定义主题色、主题广场、字体切换
- 中英文界面、登录与反馈系统

- 社区主题支持「最新 / 最热」排序；自定义主题界面改为分组配色和两栏实时预览，并移除预览中遮挡内容的假下拉菜单。
- 限时 / 计时新增「选择文稿」：限时使用长文预设，计时使用中 / 长句预设；本机文稿列表可随时切换。
- 文稿入口拆成「预设 / 本机」直接切换、当前文稿下拉选择和常驻「导入文稿」：切换来源不用开弹窗，只有选择具体文稿时才打开列表。
- 限时 / 英文倒计时改为可见的「15 / 30 / 60 / 120 + 自定义」时长组和独立的「显示倒计时」开关；自定义时长直接显示在当前项，去掉设置齿轮。
- 「刷新」改为「换一篇」并移到文稿区；切换倒计时时长不再更换当前文稿。
- 打字区改为固定顶部基线，输入高度固定；切换文稿、模式或短句 / 长句时，设置栏和输入区不再上下跳动。
- 长文自动滚动改为按行即时定位：输入法多行提交、连续删除、切换文稿都会立即对齐，删除回滚不再滞后；滚到文章底部时隐藏底部渐变遮罩。
- 刷新和路由切换时增加页面加载占位，避免异步页面加载前中间高度为 0、页脚先上移；加载状态至少展示片刻，避免闪烁。
- 本机文稿支持多篇上传、命名、编辑、拖拽排序、删除、批量导出 zip，单篇最多 888 字；只保存在当前浏览器，不计入排行榜；`/custom` 重定向到计时模式。
- 房间页打字区与限时 / 计时 / 英文模式共用同一套舞台：字号、顶部基线和输入高度一致；右侧房间面板统一为界面字号。
- 导航顺序调整为「比一比 → 限时 → 计时 → 英文 → 键盘 → 排行榜」。
- 修复编辑本机文稿时正文不回填的问题。
- 修复搜狗等输入法用 Esc 取消候选时误触发结束打字的问题：组合输入中的 Esc 只取消候选，非组合状态下的 Esc 才结束本局。
- 声明与更新日志改为统一页头 + 阅读卡片，正文、列表、链接和日期标签重新排版。
- 结算页调整按钮层级与图表颜色；自定义主题的强调色会自动适配可读性。
